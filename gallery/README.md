# Gallery

One directory per generation session: `YYYY-MM-DD-<slug>/`

- `NOTES.md` — prompt, style, ramp decisions, revision log, user feedback
- `src/` — `.pxg` sources (and any composition scripts)
- `out/` — rendered 1x PNGs (the deliverables)
- `previews/` — preview sheets and contact sheets shown to the user

Sessions are append-only history: superseded candidates stay.
